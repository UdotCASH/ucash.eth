## 🔒 Security Best Practices

### Wallet Security

1. **Only use official wallets** from verified sources
2. **Enable 2FA** on all wallet accounts
3. **Never share private keys** or seed phrases
4. **Verify addresses** before sending
5. **Use hardware wallets** for large amounts
6. **Keep software updated**
7. **Beware of phishing** attempts

### Explorer Verification

Always verify transactions and addresses through:
1. **Official explorers** (listed above)
2. **This repository** for verified addresses
3. **Official social channels** (t.me/ucash)
4. **Multiple sources** before trusting

### Red Flags

🚩 **Warning Signs of Scams:**
- Fake wallet websites
- Unofficial explorers
- Addresses not in this repository
- Unsolicited DMs asking for funds
- Promises of unrealistic returns
- Fake airdrops

**If you encounter a scam:**
- Report to security@u.cash
