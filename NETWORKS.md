## 🔗 Integration Resources

### Resolution by Naming Service

**ENS (Ethereum)**
```javascript
const provider = new ethers.JsonRpcProvider('https://eth.llamarpc.com');
const address = await provider.resolveName('ucash.eth');
```

**Base Names**
```javascript
const baseProvider = new ethers.JsonRpcProvider('https://mainnet.base.org');
const ucashBase = await baseProvider.resolveName('ucash.base.eth');
```

**Linea Names**
```javascript
const lineaProvider = new ethers.JsonRpcProvider('https://rpc.linea.build');
const ucashLinea = await lineaProvider.resolveName('ucash.linea.eth');
```

**Solana Name Service (SNS)**
```javascript
import { getSolanaName } from '@solana/sns';
const ucashSol = await getSolanaName('ucash.sol');
```

**Unstoppable Domains**
```javascript
// Resolution via UD API
const ucashUD = await resolve('ucash.u');     // Universal
const ucashPolygon = await resolve('ucash.polygon');  // Polygon-specific
```

**SpaceID (Arbitrum, BNB, Gravity)**
```javascript
const ucashArb = await resolveSpaceID('ucash.arb');
const ucashBnb = await resolveSpaceID('ucash.bnb');
const ucashG = await resolveSpaceID('ucash.g');
```

**Bitcoin Name Service (BNS)**
```javascript
const ucashBtc = await resolveBNS('ucash.btc');
```

### Cross-Chain Resolution

```javascript
const networks = {
    ethereum: {
        rpc: 'https://eth.llamarpc.com',
        ens: 'ucash.eth'
    },
    base: {
        rpc: 'https://base.llamarpc.com',
        ens: 'ucash.base.eth'
    },
    polygon: {
        rpc: 'https://polygon.llamarpc.com',
        ud: 'ucash.polygon'
    },
    solana: {
        rpc: 'https://api.mainnet-beta.solana.com',
        sns: 'ucash.sol'
    }
};

async function resolveOnAllNetworks() {
    const results = {};
    for (const [network, config] of Object.entries(networks)) {
        try {
            const address = await resolveName(config);
            results[network] = { address, success: true };
        } catch (error) {
            results[network] = { error: error.message, success: false };
        }
    }
    return results;
}
```

1. **Check this repository** - All names listed here are official
